OpenGL Graphics: 2D Card & 3D Castle

Two real-time graphics projects: an interactive 2D birthday card and a textured 3D castle scene.

Role
Individual
Tools
C++ · OpenGL · FreeGLUT
Topics
Transforms · Animation · Lighting

Challenge

Build interactive scenes from basic primitives, then move to 3D meshes, lighting and camera control.

What I did

Wrote reusable shape helpers and keyboard/mouse callbacks for the 2D card, then loaded OBJ meshes with textures, lighting and a skybox for the castle.

Outcome

A card with five interactive behaviours and a separate navigable 3D castle scene.

What the user can do

InputResult
Right clickSwitch between day and night
Left clickFade the candle flame (10 clicks to blow out)
W/A/S/D, R, Q/EMove, rotate and scale the butterfly
SpaceRelease the balloons
EnterShow the birthday message
