Reducing False Alarms in Automated Inspection

Tracing why a new automated inspection system kept rejecting good parts, and fixing the image preprocessing.

How I investigated it

  1. Spot the pattern

    A newly deployed inspection system for insulated tool handles was raising false alarms on about 30% of parts.

  2. Pull the evidence

    Extracted 200 misclassified images from the system database.

  3. Find the cause

    Histogram analysis showed brightness distributions differed between true defects and false positives, pointing to lighting.

  4. Test fixes

    Compared Gaussian blur, median filtering and bilateral filtering in a Python/OpenCV preprocessing pipeline.

  5. Confirm the result

    Adaptive histogram equalisation plus morphological closing cut lighting-induced false alarms by 45% in controlled tests on 150 samples.

Where this happened: Defect Analysis Intern, Hebei Jincheng Yuan Electric Power Tools Co., Ltd. The inspection images belong to the company and are not shown.
