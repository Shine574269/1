Weld Seam Defect Pre-screening

An image-based pre-screening tool that flags obvious defects in robotic welding seams before human inspection.

3–5 minmanual check per electrode holder
450weld images collected over three weeks
3defect types labelled
120test cases reviewed by two QC inspectors

The problem

Inspectors checked every robotic welding seam by eye. The team proposed an image-based tool that flags obvious defects first, so people only verify the suspicious ones.

Defects and how each was detected

DefectHow it was detected
CrackCanny edge detection inside the extracted seam region
PorosityContour analysis
Incomplete fusionLabelled in the ground-truth dataset for algorithm development

Pipeline

My role: image collection, Python/OpenCV seam-extraction scripts and labelling; the detection pipeline was built with a senior engineer. Company images stay with Hebei Beifang Welding Tools, so this page uses illustrations.
