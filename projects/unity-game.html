Ground-Air Dungeon Shooter — Unity

An original two-level Unity game project featuring player-controlled aircraft, enemy vehicles, obstacles and a shooting/combat system.

Game concept

Players navigate action-oriented stages and use movement and combat mechanics to defeat enemies while avoiding obstacles and threats. The Windows build preserves the original game.

Engineering

The project contains Unity scenes including UIScene, LEVEL1 and LEVEL2, plus original C# scripts, prefabs, graphics and audio assets. Aircraft artwork depicts player assets, while vehicles represent enemies.

Original game files

The executable and complete Unity project are kept in separate archives; the browser does not run Windows EXE files directly. No replacement browser game is represented as the original.

Technologies: Unity 2022.3, C#, 2D games, scene management.
