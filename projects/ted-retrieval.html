TED Talks Information Retrieval

An INT309 multimedia-information-retrieval project for searching and recommending talks in a dataset of 2,550 TED presentations.

Problem and data

The task was to rank talks against keyword queries and find similar talks based on their textual descriptions, titles and tags.

Implementation

I implemented text cleaning, TF-IDF vectorisation, cosine-similarity ranking and top-k recommendations in Python, accompanied by a Tkinter GUI with search, recommendation and dataset browsing sections.

Results and next steps

My course report evaluates the ranked results using Precision@5, Precision@10 and Recall@10. A browser-native interactive version is being prepared for deployment; the original Python implementation remains the reference.

Technologies: Python, pandas, scikit-learn, TF-IDF, Tkinter.
