DailySense — Android Activity and Scheduling App

DailySense is a collaborative CAN301 Android project bringing together smartphone-based activity recognition, scheduling and AI-generated personal summaries.

Problem

Daily movement and calendar information often live in disconnected apps. DailySense combines behavioural records, scheduled activities and personal reflections in one workflow.

System

The team's system incorporates accelerometer and gyroscope data for activity sensing, GPS/network location for context, SQLite storage, a calendar module and AI-generated daily diary entries. Activity interpretation is supported by sensor processing and rules described in the project report.

My contribution

I designed the overall interface and Figma prototypes, implemented and refined the calendar functionality, integrated it with teammates' modules, prepared workflow diagrams and documented the calendar and design decisions.

Demonstration

The original vertical demonstration video and sanitised Android Studio source are retained in the project delivery archive. These larger files will be linked once separately hosted.

Technologies: Java, Android, SQLite, Figma, mobile sensors.
