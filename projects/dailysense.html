Project overview

DailySense is a group-developed Android application that combines activity sensing, calendar tasks, and AI-supported daily summaries. Motion signals and behavioral context support movement recognition and diary generation.

Sensors, software & data flow

The Android application uses its accelerometer to measure movement, gyroscope for motion context as described in the team report, and GPS / network location to add location-aware context. Sampling, state classification and foreground services turn motion into time-stamped walking, running or stationary events; SQLite holds behavior records and tags. Calendar tasks and user moods are then combined with these records for AI-assisted daily diary generation. The report identifies walking (85%), running (78%) and stationary (92%) classification accuracy in its evaluated setting; these are team-reported values, not independently re-measured here.

How the system works

The Android app combines accelerometer and motion data with calendar events, user tags and local storage to generate a structured daily timeline. The team implemented a modular architecture: Presentation (activities and views), Business Logic (sensor perception, location, AI service), Data (SQLite records) and Utilities (permissions, notifications and APIs).

  1. Monitor motion signals and recognise movement or stillness.
  2. Store timestamped activities, personalised tags and calendar tasks.
  3. Combine sensor history and schedule details into AI-generated diary entries and daily summaries.
  4. Manage task completion and notifications through the calendar interface.
