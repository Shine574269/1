CPT306 · Game development · Unity / C#

Ground-AirDungeon Shooter

A two-level 2D action shooter built with Unity, combining enemy combat, procedural obstacle placement, player movement, power-ups and a local leaderboard.

01 Goal02 My role03 Method04 Results05 Demo06 Resources

01 · Problem & goal

Problem & goal

Build an action game with two stages that increase challenge through enemy variety, obstacles and pickups.

02 · My contribution

My contribution

The project documents movement, dashing, shooting, health, enemy spawning and game-flow interfaces in Unity/C#.

03 · Implementation approach

Implementation approach

The Unity project connects movement, dash, aim/fire, health, enemy spawning and procedural obstacles. Level 1 introduces basic opponents; Level 2 adds tougher enemy behaviors and denser encounters. Menus, settings, score display and a local leaderboard complete the game loop.

04 · Results & reflection

Results & reflection

Original Windows build, source project and design report are available. The report records navigation and power-up indicator issues; a browser build is not supplied.

Evidence & limits

The design report notes occasional enemy-navigation issues around obstacles and a power-up UI indicator needing improvement. The supplied executable targets Windows. A WebGL build has not been supplied or verified.

05 · Demonstration & visuals

Demonstration & visuals

Original controls: W/A/S/D movement, mouse + left click to aim and shoot, Left Shift to dash and Space to pause. The downloadable Windows build preserves the original game; open it on a compatible Windows machine.
