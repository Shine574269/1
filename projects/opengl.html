CPT205 — Interactive OpenGL Graphics

Two distinct graphics assignments demonstrating 2D interaction and 3D scene modelling.

Project A — Interactive Birthday Card

I used C++ and FreeGLUT to draw geometric objects, animate balloons and flowers, implement butterfly movement and transform the environment between day and night. Keyboard and mouse inputs control the graphical effects.

Project B — 3D Castle Environment

The castle project includes a genuine 3D model (building.obj), associated textures, skybox assets and C++ scene code. The geometry depicts towers, defensive walls, a courtyard, roads and trees. A model-only render was generated from the supplied OBJ for the portfolio; it must not be mistaken for a screenshot of the original compiled OpenGL program.

Methods

Geometry, transformations, animation and input handling in 2D; modelling, scene assets, textures and spatial composition in 3D.

Technologies: C++, OpenGL, FreeGLUT, OBJ model assets.
