01 · The task

Convert motor pulses into a visible measurement using an AT89C51 and four seven-segment digits.

Firmware that combines timer interrupts, an external pulse counter and a four-digit multiplexed display to show a scaled measurement from a running motor.

What I implemented

Timed pulse measurement

Timer 0 defines a measurement interval. Its interrupt stops both peripherals, reads the 16-bit Counter 1 value, calculates a scaled frequency and reloads the next interval.

Display and motor control

The main loop cycles through four display positions, maps each digit to a seven-segment pattern and blanks the display between updates. Two output pins set the motor drive direction.

From a pulse count to a display value

The source uses a nominal interval of 57 ms, then divides the frequency by 100 for display. Explore that arithmetic below; these are calculated examples, not measurements from a connected motor.

Pulse frequency is not automatically motor RPM: that conversion also needs the sensor’s pulses per revolution.

Engineering lessons & evidence

This project links register-level programming to a visible output: timer configuration, interrupt handling, integer arithmetic and display multiplexing all have to agree.

The archive identifies an AT89C51 target. It also configures a 24 MHz clock, while the source comment’s 57 ms interval corresponds to a different timer tick assumption. Clock timing, numeric range and sensor calibration need checking before treating the display as a calibrated instrument.
