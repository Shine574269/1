8051 Motor Pulse Counter

Register-level C firmware that counts motor pulses and shows the result on a four-digit seven-segment display.

Role
Individual
Tools
Embedded C · Keil µVision
Hardware
AT89C51 · 7-segment display

Diagram created for this portfolio from the original firmware; it is not a circuit schematic or a hardware photo.

Challenge

Measure a pulse rate and display it continuously on a microcontroller with only two timers and no display driver chip.

What I did

Used Timer 0 as a fixed measurement window and Counter 1 to count pulses. An interrupt reads the count and updates the value while the main loop multiplexes four digits.

Outcome

570 pulses in the 57 ms window → 10,000 Hz → the display shows 0100. Converting to RPM would also need the sensor’s pulses per revolution.
