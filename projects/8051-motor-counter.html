Embedded systems coursework · AT89C51 / C

Motor pulse measurement with an 8051

Firmware that combines timer interrupts, an external pulse counter and a four-digit multiplexed display to show a scaled measurement from a running motor.

01 Goal02 My role03 Method04 Results05 Demo06 Resources

01 · Problem & goal

Problem & goal

Convert motor pulses into a visible measurement using an AT89C51 and four seven-segment digits.

02 · My contribution

My contribution

Configured a timed measurement interval, external pulse counting, an interrupt routine and a multiplexed display loop in embedded C.

03 · Implementation approach

Implementation approach

Timer 0 defines a measurement interval. The interrupt stops the timer and external counter, reads the pulse count, updates a scaled frequency and restarts the interval. The main loop multiplexes four seven-segment digits while two output pins control motor direction.

04 · Results & reflection

Results & reflection

Original C and Keil project are linked. Timing and calibration still need board-level verification, including the source/project clock mismatch.

Evidence & limits

No fresh Keil build or physical board test is claimed. The project configures a 24 MHz clock, while the source’s nominal 57 ms interval assumes a different timer tick. Clock timing, integer range and pulses-per-revolution calibration require checking.
